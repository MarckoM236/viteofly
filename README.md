## ViteoFly

ViteoFly is a web application for creating and managing elegant digital invitations for weddings, birthdays, graduations, corporate events, and other special occasions.

The project is being developed as a Laravel-based MVP with the goal of providing a fast, responsive, and customizable invitation experience.

### Features
- **Digital invitation creation**
- **Multiple invitation themes**
- **Photo gallery**
- **Event countdown**
- **Google Maps integration**
- **RSVP confirmation**
- **Mobile-friendly design**
- **Invitation sharing via URL**
